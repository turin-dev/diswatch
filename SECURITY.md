# Security Policy

## Supported versions

DisWatch is an unreleased alpha. Security fixes are considered for the latest `main` branch; there are no stable releases yet.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository's Security tab. Private vulnerability reporting is enabled. Do not disclose suspected vulnerabilities in a public issue or discussion.

Please include the affected commit or version, impact, and steps to reproduce. Do not include real Discord credentials, tokens, QR codes, or private message contents in a report.
